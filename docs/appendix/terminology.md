# 术语表

## Candidate Question

从 PDF 原始文本中识别出的候选题块，还不是正式题目。

## Source Question

某个具体文件中出现的一道原始题。

## Canonical Question

系统归一化后用于刷题的规范题。

## Pipeline Node

题库构建流水线中的一个处理节点。

## Taxonomy

题库的科目 / 章节 / 知识点标准体系。

## Conflict

两个或更多来源对同一道题给出不一致信息。

## Quality Alert

系统根据题库内容或用户行为发现的潜在质量问题。

## Hybrid Search

关键词检索与向量检索组合。

## Adaptive Verification

仅在低置信度情况下升级模型或增加第二 Agent 验证。
