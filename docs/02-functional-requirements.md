# 4. 刷题系统

## 4.1 刷题入口

刷题入口分为快捷配置和完整设置两层：单题库入口打开快捷配置弹窗，多题库或更多设置进入统一刷题设置页。用户可以选择：

```text
一个或多个题库
→（单题库可选）科目
→（单题库可选）章节
→ 题型
→ 数量
→ 模式
→ 本次时间限制
```

多题库会先合并所选题库的题目，再统一应用题型、模式和数量限制；选择多个题库时清空并隐藏科目、章节筛选。设置页支持搜索题库、分页、全选当前页、清空选择，并实时展示可用题数和最终抽题数量。

## 4.2 刷题模式

支持：

- 顺序；
- 随机；
- 未做题；
- 错题；
- 收藏；
- 待复习。

## 4.3 即时判题

用户提交后立即返回：

- 正确 / 错误；
- 用户答案；
- 正确答案；
- 解析；
- 是否加入错题；
- 下一次复习时间。

客观题禁止依赖 LLM 实时判题。

## 4.4 限时刷题与会话状态

刷题会话支持不限时、15、30、45、60 分钟和自定义时长。自定义时长按分钟输入，范围为 1–1440 分钟。服务端接收统一的 `time_limit_seconds` 并在创建会话时生成固定 `expires_at`，客户端刷新页面只能继续显示同一截止时间。剩余 60 秒进入警告态，超时后自动结束会话并拒绝新的答题提交，同时保留已经完成的题目结果。会话状态为 `active`、`finished` 或 `expired`。

# 5. 错题本

## 5.1 自动加入

答错后自动加入。

重复答错：

```text
wrong_count += 1
```

不创建重复记录。

## 5.2 手动加入

支持用户主动收藏到错题本。

## 5.3 笔记

支持 Markdown：

- 文本；
- 列表；
- 代码；
- 链接。

后续支持：

- 图片；
- AI 润色；
- AI 总结。

## 5.4 错题状态

支持：

```text
learning
reviewing
mastered
archived
```

# 7. AI 题库构建功能

## 7.1 Document Agent

负责：

- 文本提取；
- OCR 判定；
- 页眉页脚清洗；
- 页面结构。

## 7.2 Structure Agent

负责：

- 题号识别；
- 跨页题拼接；
- Candidate Question。

## 7.3 Extractor Agent

负责：

- 题型；
- 题干；
- 选项；
- 答案；
- 解析。

## 7.4 Validator Agent

负责：

- 答案一致性；
- 选项完整性；
- 幻觉检查；
- 原文覆盖率。

## 7.5 Dedup / Merge Agent

负责：

- Hash 去重；
- 语义重复；
- 规范题合并；
- 来源绑定。

## 7.6 Classification Agent

负责：

- 科目；
- 章节；
- 子章节；
- 知识点；
- 难度。

## 7.7 Taxonomy Agent

负责：

- 判断是否新增章节；
- 合并同义章节；
- 维护知识树。

## 7.8 Conflict Agent

负责：

- 多来源答案冲突；
- 解析冲突；
- 版本差异。

## 7.9 Quality Agent

负责：

- 最终质量评分；
- 自动发布；
- 人工审核分流。
